# Raw Dataa

This folder contains the original New Jersey-Pennsylvania fast-food restaurant survey files used in Card & Krueger.

## Source 

Card, David and Alan B. Krueger (1994),
"Minimum Wages and Employment: A Case Study of the Fast-Food Industry in New Jersey and Pennsylvania",
American Economic Review, 84(4), 772-793.

The original replication data were downloaded from David Card's UC Berkeley data page. 

## Redistribution Permission

The original data files are included in this repository with permission from Professor David Card, granted by email in October 2026 for inclusion in this (non-commercial) replication repository.

## Files

- `public.dat`      – main survey dataset
- `codebook`        – original variable definitions
- `check.sas`       – original SAS code for data construction and checks
- `read.me`         – documentation accompanying the dataset
- `survey1.nj`      – first-wave survey instrument
- `survey2.nj`      – second-wave survey instrument
