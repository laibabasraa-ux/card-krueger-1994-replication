# Card & Krueger (1994) Econometric Replication 

Independent replication of Card and Krueger's (1994) study of New Jersey's minimum-wage increase using the original fast-food restaurant survey data.

## Project Aim

This project reproduces the paper's core empirical analysis in R, beginning with the New Jersey–Pennsylvania Difference-in-Differences comparison and progressing to the authors' alternative treatment-intensity and robustness specifications.

Alongside the replication, I am investigating how generative AI can support empirical economic research, with particular attention to verification, reproducibility and the points at which economist judgement remains necessary.

## Current Progress
